## Issues Flagged at Intake

### HIGH PRIORITY
1. **COLOR_MISMATCH**: ACISS spec (per system brief) calls for Obsidian #111111 / Antique Gold #B08D57 / Deep Jade #145B4B. Current CSS uses Teal #008080 / Gold #D4AF37 / Jade #00A86B. These are fundamentally different palettes. Decision needed: use the current palette (which appears intentional and well-integrated) or switch to ACISS spec colors.

2. **FONT_MISMATCH**: ACISS spec mentions Cormorant Garamond as body font. Current build uses Libre Baskerville. The current font is well-embedded with complete weight coverage (regular/bold/italic). Switching would require new font files.

3. **PUBLISHER_MISMATCH**: Copyright page reads "Published independently by the author." Per production spec, publisher should be TAYLKOMB LLC.

4. **AUTHOR_NAME_INCOMPLETE**: content.opf creator field and title page show "Michael David." Full legal name for KDP: "Michael David Warren Jr."

### MEDIUM PRIORITY
5. **TRIM_SIZE_CONFUSION**: print.css header comment says "6.69x9.61" but body comments reference "6.35x9.65." The actual @page rule uses 6.69in x 9.61in. The validation report claims 6.35" x 9.65" was applied. Need to verify which trim is correct for KDP Royal.

6. **GHOST_VIOLATIONS_SUSPECTED**: Conclusion text has AI-pattern phrasing that needs Stage 4 cleanup. Initial flags: "let your radiance emanate," "unwavering commitment," "profound awakening," "transforming trajectories," "most stunning work of art imaginable."

### LOW PRIORITY
7. **EXISTING_BUILDS**: Multiple EPUB/PDF versions exist across the repo. These appear to be iterative builds from previous production passes. Our pipeline will produce clean new outputs.

8. **WORKSHEET_FALLBACK**: worksheet-download-fallback.xhtml is marked linear="no" in spine — correct for supplementary content.
