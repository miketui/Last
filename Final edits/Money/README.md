# Money Artifacts

## Canonical publication manifest

Use `RELEASE_MANIFEST.md` as the single source of truth for publication-ready outputs:

- `Final edits/Money/RELEASE_MANIFEST.md`

It declares exactly one canonical EPUB and one canonical print PDF, including version labels, SHA256 checksums, UTC build timestamp, and distribution targets.

## Archival / superseded artifacts

Unless explicitly listed as canonical in `RELEASE_MANIFEST.md`, all other build artifacts in this directory are **archival/superseded** and should not be used for new distribution uploads.

This archival/superseded status includes (but is not limited to):

- `Curls-and-Contemplation-FINAL.epub`
- `Curls-and-Contemplation 4.epub`
- `Curls-and-Contemplation-V2-FINAL.pdf`
- `Curls & Contemplation — POD Interior (KDP Royal).pdf`
